About SpamGuard AI

SpamGuard AI is a free, open-source tool that helps everyday email users check suspicious emails before trusting them. It was built as an educational project demonstrating real-world machine learning deployment.

Who Is This For?

Students, job seekers, office workers, and anyone who wants a quick, honest second opinion on a suspicious email. No technical knowledge required.

How Was the Model Trained?

The model was trained on the Apache SpamAssassin Public Corpus, a well-known dataset of real spam and legitimate (ham) emails. The training pipeline uses TensorFlow/Keras for model development and evaluation, but the production server uses a lightweight NumPy-only forward pass to save memory.

Model Performance

All metrics below are from evaluation on a held-out test set of 889 emails (629 legitimate, 260 spam) that was never seen during training or threshold selection:

  • Accuracy: 97.86%
  • Precision: 98.79%
  • Recall: 93.85%
  • F1 Score: 96.25%
  • ROC-AUC: 0.9916
  • False Positives: 3 out of 629 legitimate emails (0.48%)
  • False Negatives: 16 out of 260 spam emails (6.15%)

Live metrics and model metadata are also exposed programmatically via the /api/model-info endpoint.

Technology Stack

  • ML Training: Python, TensorFlow/Keras, scikit-learn
  • ML Serving: NumPy-only forward pass (no TensorFlow in production)
  • Backend: Flask, Gunicorn
  • Frontend: HTML, CSS, vanilla JavaScript (no build tools, no CDN)
  • Hosting: Render (free tier, Docker runtime)

Open Source
