Feedback

We welcome your feedback, bug reports, and feature suggestions. SpamGuard AI is an open-source project and we appreciate your input.

How to Provide Feedback

GitHub Issues (Preferred)

The best way to report bugs, request features, or ask questions is through GitHub Issues. This allows us to track and prioritize your feedback publicly.

Email

You can also reach us by email. Please note that response times may vary.

What to Include in Bug Reports

  • What you expected to happen
  • What actually happened
  • Your browser and operating system
  • Steps to reproduce the issue
  • Do not include the actual email text you analyzed — describe the issue without sharing sensitive content

Feature Requests

We are happy to consider feature requests. Please describe:

  • What feature you would like
  • Why it would be useful
  • Any examples of similar features in other tools

Contributing

SpamGuard AI is open source. If you are interested in contributing code, documentation, or design improvements, please see the project README on GitHub for contribution guidelines.
